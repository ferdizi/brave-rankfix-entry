# The Old Hound on the Porch

An old hound dozes on the porch as the evening sky turns amber, dry leaves drift past, and a single firefly pauses on his nose — a small, quiet moment of bravery in simply staying still and watching the light change.

Run it with:

```sh
node main.ts
```
